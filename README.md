# noeur-apk

APK releases for Noeur, the calm food log.

Binaries only: this repo never holds source code. It only keeps the APK
files attached to releases, published automatically by the release
workflow, which lives in the private
[io-PEAK/Noeur](https://github.com/io-PEAK/Noeur) repository — that is
where all the source code is.

- Download the latest APK and read the changelog:
  https://noeur.pages.dev/download
- The SHA-256 checksum of every APK is published on the download page,
  next to the download button.
